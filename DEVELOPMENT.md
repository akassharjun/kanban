# Development

## Build

```sh
cargo build --workspace
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all -- --check
```

## TDD discipline

Every `Operation` variant lands as a failing test first. Every CLI subcommand has a happy-path snapshot and at least one error-path snapshot. The CI gate runs the full test suite — no `#[ignore]` lands in `main` without a comment explaining why.

## Migrations

SQL files in `crates/kanban-core/migrations/NNNN_name.sql` are embedded with `include_str!` and applied in numeric order on `Workspace::open`. **`0001_init.sql` is frozen after v1 ships** — schema changes go in `0002_*.sql` and beyond. Never edit a released migration.

## Snapshot tests

CLI tests use [`insta`](https://insta.rs). After a change to expected output:

```sh
cargo insta review --workspace-root crates/kanban-cli
```

Approve or reject each diff hunk. Snapshots live in `crates/kanban-cli/tests/snapshots/`.

## Performance

`crates/kanban-cli/tests/perf.rs` checks cold-start <50ms p95. It's `#[ignore]` by default; run locally with `cargo test --workspace -- --ignored`.

## Tauri GUI (Spec #2)

The desktop app is the `kanban-tauri` crate (Rust shell) plus the `ui/` package
(Vite + React 19 + Tailwind v4). Package manager is **pnpm**.

```sh
pnpm --dir ui install
pnpm --dir ui dev               # Vite dev server on http://localhost:1420
pnpm --dir ui tauri dev         # Tauri shell pointed at Vite
pnpm --dir ui tauri build       # Production .app + .dmg
```

### Apple Silicon + nvm note

If your default `node` is an **x86_64** build (e.g. installed via nvm) on an
Apple Silicon Mac, `vite`/`vitest` crash with `Cannot find module
'@rollup/rollup-darwin-x64'` because pnpm installed the **arm64** native
binaries. Run the UI tooling under a native arm64 node — e.g. with Homebrew's
node first on `PATH`:

```sh
PATH="/opt/homebrew/bin:$PATH" npx pnpm@9.12.0 <script>
```

### Tests

```sh
pnpm --dir ui typecheck         # tsc --noEmit
pnpm --dir ui lint              # eslint (flat config), --max-warnings 0
pnpm --dir ui test:unit         # Vitest + React Testing Library
```

End-to-end (`tauri-driver` + Playwright) coverage is **deferred to Spec #3** —
`tauri-driver` has no macOS WebDriver support. See `ui/e2e/README.md`.

### Generated bindings

`tauri-specta` generates `ui/src/data/bindings.ts` from the Rust command set. It
is **git-tracked** and regenerated by the `export_bindings` test during
`cargo test`; CI fails if the committed copy drifts. After changing a Tauri
command, run `cargo test -p kanban-tauri --test export_bindings` and commit the
updated file.

### Unsigned builds

The first ship is unsigned. A downloaded `.app` may be quarantined on macOS:

```sh
xattr -dr com.apple.quarantine /Applications/kanban.app
```

Apple Developer signing lands in Spec #3.
